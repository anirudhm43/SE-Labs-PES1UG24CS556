# Lab 5 – Static Code Analysis

[Link to the repo](https://github.com/anirudhm43/L5_07_campus_shuttle)

## Overview
This lab focuses on performing static code analysis on a Python-based Campus Shuttle System using **Pylint, Bandit, and Flake8**. The objective is to identify code quality issues, potential security concerns, and coding standard violations, then fix the reported issues and verify the improvements.

## Project Repository
**Campus Shuttle System – Lab 5**

[View the Lab 5 source code and deliverables](https://github.com/anirudhm43/L5_07_campus_shuttle)

## Tools Used
- **Pylint:** Code quality analysis and linting.
- **Bandit:** Security-focused static analysis for Python.
- **Flake8:** PEP 8 style and formatting checks.

## Key Tasks
- Run the original program and capture the initial analysis reports.
- Identify and document static analysis findings.
- Fix issues involving input validation, exception handling, mutable default arguments, naming, formatting, and other code quality concerns.
- Generate before-and-after reports for all three analysis tools.
- Document the findings in `issues.md` and the learning outcomes in `reflection.md`.

## Final Verification

- **Bandit:** No issues identified.
- **Flake8:** No reported violations.
- **Program execution:** Tested successfully.
